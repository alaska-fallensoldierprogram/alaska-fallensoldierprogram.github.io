# Alaska Airlines Fallen Soldier Program — Website

This repo hosts the Fallen Soldier Program website via GitHub Pages.

Live site: https://alaska-fallensoldierprogram.github.io

## How to edit
The entire site is one file: `index.html`. To make a change:
1. Click `index.html` in this repo
2. Click the pencil icon (Edit)
3. Make your change and commit — the live site updates automatically within a minute or two
